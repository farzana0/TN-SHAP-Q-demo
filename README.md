# TN-SHAP-Q

Exact, query-efficient **Shapley attribution for quantum neural networks (QNNs)** via multilinear
extensions. This is the public, reproducible code of the paper

> *TN-SHAP-Q: Exact Multilinear Extensions of Quantum Neural Networks for Shapley Attribution of
> Features and Gates.*

It contains **one self-contained notebook per paper experiment**, the shared [`tnshapq`](tnshapq/)
package that all notebooks import, the generated figures and machine-readable results, and an
independent calculation audit. Everything runs on CPU (Qiskit statevector, NumPy — no GPU/torch) and
is byte-stable.

## Multilinear Extension of the circuit components

A single-$R_Y$ QNN is **exactly multilinear** in the lifted features $\phi(x_i)=[1,\cos x_i,\sin x_i]$.
So when you mask features (or remove gates) against a baseline, **the multilinear extension of the
induced cooperative game is the very function the circuit computes — not a fitted surrogate.**
First-order Shapley values are then the **Owen diagonal integral**

$$\phi_i=\int_0^1 \partial_i F(t\mathbf 1)\,dt,\qquad
\partial_i F(t\mathbf 1)=F(z_i{=}1,z_{-i}{=}t)-F(z_i{=}0,z_{-i}{=}t),$$

which $M$-point Gauss–Legendre quadrature evaluates **exactly once $M\ge\lceil P/2\rceil$** for $P$
players, in $2PM$ extension evaluations versus $2^P$ for coalition enumeration. Order-$k$ interaction
indices come from the same extension, exact once $M\ge\lceil (P-k+1)/2\rceil$ at $2^kM$ evaluations per
coalition — a threshold that *decreases* with interaction order.

## Repository layout

| path | contents |
|---|---|
| [`tnshapq/`](tnshapq/) | reusable core: single-$R_Y$ QNN + feature game (`qnn`), gate game + QAOA example (`gate_game`), exact $2^P$ enumeration (`exact`), Owen integral Shapley/interactions for features and gates, exact and finite-shot (`owen`), SVQX baselines (`svqx`), Q-LIME (`qlime`), datasets (`datasets`), metrics (`metrics`) |

## Install and reproduce

```bash
pip install -r requirements.txt

# regenerate every figure + results/NN.json (CPU only, byte-stable)
for nb in notebooks/[0-9][0-9]_*.ipynb; do
  python -m nbconvert --to notebook --execute --inplace "$nb"
done

# independent verification of all results -> results/AUDIT.md
python audit.py
```

Pin all thread pools to one worker (`OMP_NUM_THREADS=MKL_NUM_THREADS=OPENBLAS_NUM_THREADS=RAYON_NUM_THREADS=1`)
for byte-identical output; the `tnshapq` package sets these on import.
